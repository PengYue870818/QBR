# QBR
Numerical validation suite for the MMSIS-QBR geometry–environment separation and virtual-response formalism: reduced-channel Wigner factorization, frozen Hermite–Gaussian kernel folding, spectral-band ruler, remainder-budget control, and independent reduced-channel reconstruction.

This program is a companion to the work by Peng Yue and Jinghui Zhang on calibrated single-window factorization in open quantum systems. It is designed to test, in a numerical setting, whether the main idea of the work holds up: that within a single observation window, one can separate the contribution that comes from the frozen geometry of the system, as seen by a detector, from the contribution that comes from the environment acting during that same window. The work calls these two parts the instrument-locked spatial slope and the folded environmental lever. The code implements a reduced version of the full theoretical framework, meaning that it does not solve the complete two-dimensional quantum transport equation, but instead evaluates the two key ingredients independently and then checks whether their product reproduces the expected momentum response.

The program is written in Python and requires Python version 3.7 or newer. It uses only two external libraries, NumPy and Matplotlib, along with a few standard modules that come with Python itself. No other packages are needed. A scientific Python environment such as Anaconda is convenient, but any modern Python installation will work after running a simple command to install the two required libraries. The calculations are not computationally heavy, but the default grid sizes are fairly large, so a computer with at least eight gigabytes of memory is recommended. The program runs entirely on a standard processor; no GPU or parallel computing is required.

To run the code, you simply place the script in a folder where you have write permission and execute it from a terminal with the command python qbr_validation.py. The program will then perform all of its checks automatically. It computes the geometry factor from the detector point-spread function and the spatial curvature of the potential, builds the environmental kernel from a simplified momentum-channel model, folds that kernel over the observation window to obtain the environmental lever, and then verifies whether the leading response follows the expected multiplicative structure. It also runs a series of consistency scans, including changing the strength of the environmental diffusion to confirm that the geometry factor remains fixed, and it carries out an independent reconstruction of both the geometry and the environmental kernel using different numerical quadrature methods to guard against implementation errors.

When the run is finished, all results are saved to a folder named figs_top_journal_qbr by default, though you can change this by editing one line in the script. The folder will contain a set of figures in PNG format, each illustrating a different aspect of the validation, such as the spatial pairing, the time kernel, the spectral ruler, the remainder budget, and the co-scaling scans. For every figure, there is also a CSV file containing the underlying data. A summary file collects all the key numerical values from the run, including pass or fail flags for the various checks. If you need to adjust physical parameters, such as the bath temperature, the window duration, or the detector width, or if you want to change the numerical grid sizes, you can do so by editing the configuration object near the bottom of the script. The code is deliberately structured so that all user-adjustable settings are gathered in one place, making it easy to explore different parameter regimes.
